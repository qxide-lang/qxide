# qxide.dev (`site/`)

Website for `qxide.dev` in the `qxide` repository.

**Status:** Placeholder page only — design chosen later.

## Stack

- **Framework & build:** Vite 8 + React 19 + TypeScript
- **Design system & styling:** Astryx (`@astryxdesign/core`, `theme-neutral` `0.7.16`, pre-built CSS, no build plugin) and `@stylexjs/stylex`
- **Runtime:** Node 22+

## Commands

Run all commands inside `site/`:

- `npm install` — Install dependencies
- `npm run dev` — Start the Vite dev server (`http://localhost:5173`)
- `npm run build` — Run `tsc --noEmit` then `vite build` (output directory: `dist/`)
- `npm run preview` — Serve `dist/` locally
- `npm run astryx -- <cmd>` — Run the Astryx CLI (e.g., `component Button`, `template --list`, `doctor --built dist`)

## Deploy to Cloudflare Pages

Static site — no functions and no secrets needed.

- **Root directory:** `site`
- **Build command:** `npm run build`
- **Build output directory:** `dist`
- **Node version:** Set the `NODE_VERSION` environment variable to `22` (or newer)
