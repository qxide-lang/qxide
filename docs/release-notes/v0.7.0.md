# qxide v0.7.0

`qxide v0.7.0` builds on `v0.6.0` with `.qx` modules (`import`, `public`), a package manager (`qxide.toml`, `qxide.lock`, and registry commands `qxide add`, `qxide remove`, `qxide install`, `qxide publish`, and `qxide search`), and new CLI commands (`qxide fmt`, `qxide repl`, `qxide explain`, and a package layout for `qxide new`). This release also derives an independent seed for each shot, tightens `.qx` linearity checks (`Q0315`), and rejects non-finite rotation angles (`Q0411`). For Rust library users, `qxide::shot_seed` and `Circuit::simulate_shots` are new, `Circuit::rx`, `Circuit::ry`, and `Circuit::rz` now panic on non-finite angles, and package manager dependencies are gated behind the default `cli` feature.

## Breaking changes

- **New `.qx` keywords**: `import` and `public` are now keywords in `.qx` and can no longer be used as identifiers.
- **Non-finite rotation angles**: `Circuit::rx`, `Circuit::ry`, and `Circuit::rz` now panic on `NaN` or infinite angles instead of producing a `NaN` state vector, `0` measurements, and invalid `rx(NaN)` output from `to_qasm`. In `.qx`, non-finite rotation angles are rejected with `Q0411`.
- **Stricter `.qx` linearity checks**: Consuming a qubit in the right operand of `&&` or `||`, or consuming an operand borrowed by the same call or gate (for example `rx(q, eat(q))`), is now rejected at check time with `Q0315` and `Q0301`.
- **Nesting limit on `.qx` chains**: Operator chains (`a + b + ...`) and index/method chains (`r[0][0]...`) now count toward the 128-level nesting limit (`Q0106`), rejecting chains longer than about 120 operators.
- **Package layout in `qxide new`**: `qxide new` now creates `qxide.toml`, `src/main.qx`, `README.md`, and `.gitignore` instead of `main.qx` and `README.md`, and rejects arguments starting with `-` as a usage error.
- **Strict CLI argument checks**: `qxide bell`, `--version`, and `--help` now reject extra arguments with exit code 2.

## New features

- **Modules and imports**: Every `.qx` file is now a module supporting `public` functions, Java-style `import pkg.module.function;` and `import pkg.module.*;` declarations, and import errors `Q0501`–`Q0510`. Inside a project, `qxide run`, `qxide check`, and `qxide qasm` default to `src/main.qx` when no file argument is passed.
- **Package manager**: Added a package manager with `qxide.toml` manifests, `qxide.lock`, a GitHub-hosted index registry (`registry-template/`), commands `qxide add`, `qxide remove`, `qxide install`, `qxide publish`, and `qxide search`, `--offline`/`QXIDE_OFFLINE=1`, `--registry`/`QXIDE_REGISTRY`, cache storage in `QXIDE_HOME` (default `~/.qxide`), and package errors `Q0601`–`Q0617`.
- **CLI commands**: Added `qxide new <NAME>` (deriving the package name from the folder name), `qxide fmt <FILE> [--check]`, `qxide repl [--seed S]`, and `qxide explain <CODE>` (prints the entry from `docs/error-codes.md`, including `Q05xx` and `Q06xx` errors).
- **Per-shot seeding API**: Added `qxide::shot_seed(seed, shot)` and `Circuit::simulate_shots(backend, seed, shots)`.
- **New error codes**: Added `Q0315` (qubit consumed in the right operand of `&&` or `||`), `Q0411` (non-finite rotation angle), and `Q0412` (internal error when the checker and interpreter disagree, replacing `Q0311`).
- **Browser playground**: The `.qx` front end and simulator compile to WebAssembly (`crates/qxide-wasm`, unpublished) for `qxide.dev`, with CI checking that its output matches the CLI.

## Fixes

- **Seeded multi-shot sampling**: Replaced per-shot `S + k` seeding with independent `(S, k)` seeds via `qxide::shot_seed` and `Circuit::simulate_shots`. Runs remain reproducible for a given `--seed`, though counts and single-shot results differ from `0.6.0` across `qxide run`, `qxide bell`, `qxide repl`, and the browser playground.
- **Checker, interpreter, and WebAssembly**: Rejected non-finite rotation angles with `Q0411`, closed linearity check gaps (`Q0315`, `Q0301`), fixed stack overflows on long expression chains during `check`, `run`, and `qasm`, made `qreg(4294967297)` on `wasm32` fail with `Q0409` instead of wrapping to 1 qubit, changed `int.MIN % -1` to return `0` instead of `Q0401`, and treated bare qubit statements (`q;`) as no-ops instead of `Q0312`.
- **CLI (`qxide fmt`, `qxide run`, `qxide new`)**: Fixed `qxide fmt` rejecting valid CRLF files with line breaks inside string literals, allowed flags before or after the file path in `qxide run` (for example `qxide run --shots 2 file.qx`), and stopped `qxide new` from leaving an empty folder behind when writing a file fails.
- **REPL (`qxide repl`)**: Rejected nested `return` statements and unmatched closing brackets (such as `}`), fixed trailing `//` comments failing with `Q0105`, ignored a leading UTF-8 BOM in piped input, and showed typed input instead of the internal `println("{}", …)` wrapper in diagnostics.
- **Package archives and semver resolution**: Rejected archive entries with trailing dots or spaces, Windows device names (`CON`, `NUL`, …), Windows-invalid characters, or case-only duplicates before unpacking (`Q0610`), in `qxide publish` (`Q0614`), and in registry CI; skipped symlinked `README*`/`LICENSE*` files in `qxide publish`; disallowed selecting or publishing versions with semver build metadata (such as `1.0.0+x`) and rejected same-precedence duplicates in registry CI.
- **Registry downloads, index parsing, and CI**: Reported any non-zero `curl` exit as `Q0608`, passed `--globoff` to `curl`, and wrote downloads to exclusively created files under `$QXIDE_HOME/registry/tmp`; matched registry CI (`validate.py`) to the client index parser, skipped unusable index lines (reporting `Q0609` only when none remain), rejected self-dependencies (`Q0606`), ordered pre-releases by semver precedence in `build_search.py`, and rejected `"v": true` and `config.json` changes in package PRs.
- **Lockfile checks**: Validated the full dependency graph for lock freshness in `qxide run` and `qxide install --locked` (`Q0612`) and validated package names in `qxide.lock` (`Q0603`).

## Rust library

- Added `qxide::shot_seed(seed, shot)` to derive an independent seed per shot and `Circuit::simulate_shots(backend, seed, shots)` to iterate over `Result<Shot, SimError>` using `shot_seed`.
- `Circuit::simulate` and `Circuit::simulate_with` are unchanged and continue to run a single shot with the exact seed provided.
- `Circuit::rx`, `Circuit::ry`, and `Circuit::rz` now panic when given `NaN` or an infinite angle.
- Package manager dependencies are gated behind the default `cli` feature, so compiling with `default-features = false` (`--no-default-features --lib`) keeps the library dependency-free.

## Install

All installation methods below install the same `qxide` CLI binary.

Prebuilt binaries from GitHub Releases via the `qxide.dev` install script:

```sh
# Linux / macOS
curl --proto '=https' --tlsv1.2 -LsSf https://qxide.dev/install.sh | sh
```

```powershell
# Windows (PowerShell)
powershell -ExecutionPolicy Bypass -c "irm https://qxide.dev/install.ps1 | iex"
```

From `crates.io`:

```sh
cargo install qxide
```

From PyPI (bundles the same CLI binary):

```sh
pip install qxide
```
