# qxide v0.5.0

`qxide v0.5.0` introduces the `.qx` quantum programming language and the `qxide` CLI (`run`, `check`, `qasm`) on top of the existing `qxide` Rust simulation engine. The Rust library public API is unchanged from `v0.4.1`.

## Highlights

- **New `.qx` language & CLI**: Write quantum programs in `.qx` files and check, run, or export them to OpenQASM 3 with `qxide check`, `qxide run`, and `qxide qasm`.
- **Flow-sensitive linear qubit safety**: The static checker prevents use-after-measurement, requires every qubit to be measured or discarded, and rejects duplicate gate operands.
- **Java-style syntax & expanded type system**: Updated declarations (`int`, `double`, `boolean`, `Qubit`, `QReg`, `Bit`, `BitReg`, `final`) and explicit `return` statements replace the unreleased MVP syntax on `main`.
- **Rotation gates**: Added `rx`, `ry`, and `rz` gates accepting `double` angle arguments.
- **Clear bit & multi-shot output**: `BitReg` displays as an array (`[0, 1, 1]`), with `to_binary()` and `as_int()` helpers and grouped outcome tables for multi-shot runs.
- **`rustc`-style diagnostics**: English error messages with codes `Q01xx`–`Q04xx`, `line:column` spans, and `note`/`help` guidance.
- **Safety hardening**: Oversized stabilizer runs are rejected before allocation (`Q0406`), UTF-8 BOM files are accepted, and recursion/nesting limits are enforced.
- **Documentation & CI validation**: Rewritten English `README.md`, Korean translation at `README.ko.md`, design document at `docs/design/qx-language.md`, and Qiskit validation of OpenQASM 3 output in CI.

## Breaking changes

- **Rust library (`qxide` crate)**: None. The public Rust API is unchanged since `v0.4.1`.
- **`.qx` language (early adopters of the unreleased MVP syntax on `main` only)**:
  - Declarations now use Java-style syntax instead of `let`, `fn`, and `mut`:
    - Variable declarations: `int x = 1;`, `Qubit q = qubit();`, `Bit m = measure(q);`, and `final` for immutable bindings.
    - Function declarations: `void main()` and typed functions such as `int add(int a, int b) { return a + b; }`.
  - Tail-expression returns have been removed; functions that return a value must use an explicit `return` statement.
  - Using `let`, `fn`, or `mut` now fails with error `Q0110` and includes a migration hint.

## Language

- **Front end & execution**: Hand-written front end paired with a flow-sensitive static checker, an interpreter that constructs a `qxide` `Circuit`, and OpenQASM 3 export.
- **Linear qubit checking**: Enforces linear usage of `Qubit` values across control flow—rejecting use after measurement, unmeasured/undiscarded qubits, and duplicate gate operands.
- **Types & declarations**:
  - Supports 64-bit `int`, `double` (new), `boolean`, `Qubit`, `QReg`, `Bit`, and `BitReg`.
  - Uses Java-style declarations (`int x = 1;`, `Qubit q = qubit();`, `Bit m = measure(q);`, `void main()`, `int add(int a, int b) { return a + b; }`, and `final`).
- **Parametric rotation gates**: Added `rx`, `ry`, and `rz` accepting `double` angles.
- **Bit representation & helpers**:
  - `BitReg` prints as an array with `r[0]` first (e.g., `[0, 1, 1]`).
  - `r.to_binary()` formats the register highest bit first (e.g., `0b110`).
  - `r.as_int()` converts the register to an integer with `r[0]` as the least significant bit (e.g., `6` for `[0, 1, 1]`).
- **Diagnostics**: English `rustc`-style diagnostics with error codes `Q01xx`–`Q04xx`, `line:column` positions, and `note`/`help` lines (including `Q0110` for removed `let`/`fn`/`mut` keywords and `Q0406` for oversized stabilizer runs).
- **Safety & robustness**:
  - Refuses huge stabilizer runs before allocating memory (`Q0406`).
  - Accepts source files starting with a UTF-8 BOM.
  - Enforces recursion and syntax nesting limits.
- **Examples**: Added starter `.qx` programs under `examples/qx/` (`bell`, `ghz`, `teleport`).

## CLI

- `qxide run <FILE> [--shots N] [--seed S]`: Checks and executes a `.qx` file by building and simulating its `qxide` `Circuit`.
  - Supports `--shots N` for repeated sampling and `--seed S` for deterministic runs.
  - Multi-shot runs print a summary table grouped by measurement outcome, such as `[0, 1, 1]  0b110 = 6  ×503`, with each outcome's printed output indented beneath its row.
- `qxide check <FILE>`: Runs parsing, type checking, and flow-sensitive linear-qubit analysis without executing the circuit.
- `qxide qasm <FILE>`: Exports the circuit built from a `.qx` file as OpenQASM 3.

## Library

- The `qxide` Rust crate public API has no breaking changes and remains compatible with `v0.4.1`.
- The `.qx` interpreter lowers directly into the existing `qxide` `Circuit` representation.

## Docs

- Rewrote `README.md` in English with updated installation instructions (`qxide.dev/install.sh`, `qxide.dev/install.ps1`, `cargo install qxide`, `pip install qxide`).
- Moved the Korean README to `README.ko.md`.
- Added the language design document at `docs/design/qx-language.md`, outlining the language semantics and a native-code compilation roadmap (typed IR, Cranelift first, LLVM optional).
- Updated CI to validate OpenQASM 3 output generated from the `.qx` examples against Qiskit.

## Install

Install the `qxide` CLI using the install script, `cargo`, or `pip`:

```sh
# Linux / macOS
curl --proto '=https' --tlsv1.2 -LsSf https://qxide.dev/install.sh | sh
```

```powershell
# Windows
powershell -ExecutionPolicy Bypass -c "irm https://qxide.dev/install.ps1 | iex"
```

```sh
# Cargo
cargo install qxide
```

```sh
# Python / pip
pip install qxide
```

Verify the installation:

```sh
qxide --version
```
